# 🎓 國小數學互動學習館・雙人搶答對決競技場 (Math Battle Arena)

專為國小高年級（國小 6 年級上學期）數學課堂設計的雙人搶答對抗互動遊戲平台。支援大螢幕投影、觸控電子白板、平板與電腦同台競賽。

---

## 🌟 遊戲大廳陣容

### 1. 🌲 【植樹與間隔問題 雙人搶答對決】（第 3 單元 3-3）
* **題型分類**：
  * 🔢 **路燈編號問題**：第 $A$ 號到第 $B$ 號路燈相距幾公尺？核心：間隔數 $= B - A$。
  * 🌲 **直線求數量**：兩端都設（$+1$）、一端設一端不設（$=N$）、兩端都不設（$-1$）以及道路「兩側（$\times 2$）」雙倍題。
  * 📏 **求間距與全長**：綁氣球、插國旗、放盆栽等情境，總長 $\div$ 間隔數 $=$ 間距。
  * 🔄 **封閉圖形植樹**：圓形水池、正方形花園外圍，核心：棵數 $=$ 間隔數 $=$ 周長 $\div$ 間距。
  * 🔥 **四合一全能大亂鬥**：四種題型隨機各抽考 1 題。
* **動態隨機改數字**：
  * 每種類型提供 15~30 組以上完全整除之生活化數字組合。
  * 內建防重複記憶機制，保證每次出現題目時數字與答案均不相同。
* **向量 SVG 動態圖解**：
  * 每題搶答完畢後，彈出視窗以動態 SVG 繪製數線、端點標記、弧線間距或封閉水池環狀路徑，並列出解題步驟。

### 2. ⚡ 【和差積商不變量 雙人搶答對決】（第 3 單元 3-2）
* **題型分類**：
  * 🤝 **和不變**：晝夜 24 小時、互贈移轉。
  * ⏳ **差不變**：年齡成長、同增同減。
  * 📐 **積不變**：碾米分裝、路程工程（反比）。
  * 🎯 **商不變**：杯子蛋糕、劃零餘數（正比）。
  * 🔥 **四合一綜合**：各抽 1 題綜合考驗。

### 3. 🏰 【數之咒印：禁忌地牢逃脫】（第 3 單元 數量關係 全單元沉浸密室）
* **背景情境**：古老黑魔法地牢密室逃脫，涵蓋燭光探照、逼真心跳、實體銅鎖與石門轟鳴。
* **10 大關卡（P.38 ~ P.51 全面映射）**：
  * 🩸 **第一密室**：血色圖騰的週期循環（3-1 週期除法與餘數計數）
  * 🦴 **第二密室**：骸骨牢籠的幾何生長（3-1 三角形/正方形骨杖生長公差）
  * ⚖️ **第三密室**：雙子血月的平衡之秤（3-2 和不變，晝夜 24 小時）
  * ⏳ **第四密室**：詛咒幽靈的永恆歲月（3-2 差不變，年齡差恆定）
  * 🧪 **第五密室**：毒液水牢的逆流閥門（3-2 積不變，容積與流速時間反比）
  * 🪙 **第六密室**：貪婪石像的魂幣代價（3-2 商不變，單價等比關係）
  * 📏 **第七密室**：幽靈長廊的冥燈指引（3-3 兩編號間隔數與總長）
  * ⛩️ **第八密室**：斷魂長廊的雙重結界（3-3 兩端皆設 ＋ 走廊兩側雙倍）
  * ⭕ **第九密室**：銜尾巨蛇的環形石陣（3-3 封閉圓形迴路，棵數＝間隔數）
  * 🏛️ **第十密室**：禁忌之門的四象陣眼（P.51 綜合題，長寬四角最大公因數間距）
* **獨家課堂特色設計**：
  * 🌐 **中英雙語無縫切換**：頂部一鍵切換純中文或純英文介面，非干擾式中英對照，照顧不同語系學生。
  * 🔊 **原生 Web Speech 語音報讀**：點擊「🔊 朗讀題目」即可自動以標準中/英文朗讀情境故事與謎題算式。
  * 🔑 **防抄襲座號種子碼**：每位學生輸入班級座號後生成專屬數值與開鎖密碼，鄰座無法互相抄襲。
  * ⚙️ **實體四位旋轉銅鎖**：支援上下撥動輪盤、快捷鍵盤輸入與拉栓開門動畫。
  * 📖 **動態 SVG 染血筆記**：針對學生當前題目的個別數值即時繪製向量數線與幾何剖析圖（純思維鷹架，不直接洩露答案）。
  * 🚪 **彈性換座號/登出**：隨時切換座號重啟挑戰，方便老師教學演示或多組學生輪替。

### 4. ⏳ 【時空星門：質源鐘樓與雙重神印】（第 01 單元 最大公因數與最小公倍數 全單元密室）
* **背景情境**：蒸氣龐克發條鐘樓與古代星門，涵蓋質源原石辨識、3的倍數數位和破譯、短除法法陣、雙星互質、長方形石板裁切與同頻共振逃脫。
* **10 大關卡（P.4 ~ P.21 全面映射）**：
  * 🌟 **第一密室**：質源之石的辨識（1-1 質數與合數基礎概念，大於1且因數只有1和自己）
  * 🔢 **第二密室**：禁忌數陣的倍數破譯（1-1 3的倍數數位和判別法，快速剔除合數）
  * 🌳 **第三密室**：生命之樹的質因數萃取（1-2 樹狀圖質因數分解與因數加總）
  * 🪜 **第四密室**：短除符文的能量還原（1-2 短除法質因數分解，課本青蛙跳石逆推題）
  * ⚡ **第五密室**：雙星結界：互質之門（1-3 互質定義：最大公因數為 1）
  * 💎 **第六密室**：共鳴晶核：最大公因短除陣（1-3 短除法求兩數最大公因數，左側質因數相乘）
  * 📐 **第七密室**：方石祭壇的等份切割（1-3 最大公因數生活應用：長方形紙板裁切最大正方形）
  * 🔄 **第八密室**：雙星軌道：公倍共振（1-4 短除法求兩數最小公倍數，L型外圍連乘）
  * ⏰ **第九密室**：星光之鐘：雙重週期共振時刻（1-4 最小公倍數生活應用：雙燈號/班車下一次同時發生時刻）
  * 🏛️ **第十密室 (終極脫出)**：神殿地磚的幾何嵌合與終極封印（1-4 綜合題：長方形磁磚拼排最小正方形塊數計算）

## 🎮 課堂對戰機制與教學功能

1. **公平座號抽籤系統**：
   * 內建 1～26 號（或自訂範圍）隨機滾輪抽籤，支援「避免重複中籤」，讓每位學生都有機會上台。
2. **搶答與防猜處罰機制**：
   * 8 個選項（1 正解 + 7 個精準學生迷思干擾項）。
   * 答錯立即觸發「冰凍懲罰 5 秒」並倒數計時，另一隊可抓緊時間冷靜推導搶答。
3. **原生 Web Audio API 音效**：
   * 搶答聲、正確叮咚聲、答錯低音蜂鳴、最後 5 秒緊張心跳聲、勝利歡呼禮花音效，純程式合成免載入外部音檔。
4. **鍵盤與大螢幕觸控最佳化**：
   * **全螢幕**：按鍵盤 <kbd>F</kbd>
   * **切換音效**：按鍵盤 <kbd>M</kbd>
   * **紅隊快捷鍵**：<kbd>1</kbd> ~ <kbd>4</kbd> / <kbd>Q</kbd> ~ <kbd>R</kbd>（或 <kbd>A</kbd> ~ <kbd>V</kbd>）
   * **藍隊快捷鍵**：<kbd>7</kbd> ~ <kbd>0</kbd> / <kbd>U</kbd> ~ <kbd>P</kbd>（或 <kbd>J</kbd> ~ <kbd>.</kbd>）
   * **下一題**：按空白鍵 <kbd>Space</kbd> 或 <kbd>Enter</kbd>
