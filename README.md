# 🎓 國小數學互動學習館・雙人搶答對決競技場 (Math Battle Arena)

專為國小高年級（國小 6 年級上學期）數學課堂設計的雙人搶答對抗互動遊戲平台。支援大螢幕投影、觸控電子白板、平板與電腦同台競賽。

---

## 🌟 遊戲大廳陣容

### 1. 🌲 【植樹與間隔問題 雙人搶答對決】（第 3 單元 3-3）
* **題型分類**：
  * 🔢 **路燈編號問題**：第 $A$ 號到第 $B$ 號路燈相距幾公尺？核心：間隔數 $= B - A$。
  * 🌲 **直線求數量**：兩端都設（$+1$）、一端設一端不設（$=N$）、兩端都不設（$-1$）以及道路「兩側（$\times 2$）」雙倍題。
  * 📏 **求間距與全長**：綁氣球、插國旗、放盆栽等情境，總長 $\div$ 間隔數 $=$ 間距。
  * 🔄 **封閉圖形植樹**：圓形水池、正方形花園外圍，核心：棵數 $=$ 間隔數 $=$ 周長 $\div$ 間距。
  * 🔥 **四合一全能大亂鬥**：四種題型隨機各抽考 1 題。
* **動態隨機改數字**：
  * 每種類型提供 15~30 組以上完全整除之生活化數字組合。
  * 內建防重複記憶機制，保證每次出現題目時數字與答案均不相同。
* **向量 SVG 動態圖解**：
  * 每題搶答完畢後，彈出視窗以動態 SVG 繪製數線、端點標記、弧線間距或封閉水池環狀路徑，並列出解題步驟。

### 2. ⚡ 【和差積商不變量 雙人搶答對決】（第 3 單元 3-2）
* **題型分類**：
  * 🤝 **和不變**：晝夜 24 小時、互贈移轉。
  * ⏳ **差不變**：年齡成長、同增同減。
  * 📐 **積不變**：碾米分裝、路程工程（反比）。
  * 🎯 **商不變**：杯子蛋糕、劃零餘數（正比）。
  * 🔥 **四合一綜合**：各抽 1 題綜合考驗。

## 🎮 課堂對戰機制與教學功能

1. **公平座號抽籤系統**：
   * 內建 1～26 號（或自訂範圍）隨機滾輪抽籤，支援「避免重複中籤」，讓每位學生都有機會上台。
2. **搶答與防猜處罰機制**：
   * 8 個選項（1 正解 + 7 個精準學生迷思干擾項）。
   * 答錯立即觸發「冰凍懲罰 5 秒」並倒數計時，另一隊可抓緊時間冷靜推導搶答。
3. **原生 Web Audio API 音效**：
   * 搶答聲、正確叮咚聲、答錯低音蜂鳴、最後 5 秒緊張心跳聲、勝利歡呼禮花音效，純程式合成免載入外部音檔。
4. **鍵盤與大螢幕觸控最佳化**：
   * **全螢幕**：按鍵盤 <kbd>F</kbd>
   * **切換音效**：按鍵盤 <kbd>M</kbd>
   * **紅隊快捷鍵**：<kbd>1</kbd> ~ <kbd>4</kbd> / <kbd>Q</kbd> ~ <kbd>R</kbd>（或 <kbd>A</kbd> ~ <kbd>V</kbd>）
   * **藍隊快捷鍵**：<kbd>7</kbd> ~ <kbd>0</kbd> / <kbd>U</kbd> ~ <kbd>P</kbd>（或 <kbd>J</kbd> ~ <kbd>.</kbd>）
   * **下一題**：按空白鍵 <kbd>Space</kbd> 或 <kbd>Enter</kbd>
